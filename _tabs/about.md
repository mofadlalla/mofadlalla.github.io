Hi, I'm **Mohamed Fadlalla**.

I am a **Software Engineer at Google** based in **Brooklyn, NY**.

I specialize in full-stack architecture and system design, with a particular focus on solving scaling challenges. My background is in **Computer Information Systems (CIS)** from the **University of New Hampshire**, where I learned that the best code is the code you don't have to write—but the second best is the code that scales effortlessly.

### 🛠️ What I'm Building

By day, I work on large-scale distributed systems. By night, I am an indie hacker building tools that bridge the gap between code and creativity.

Currently, I am building a **Cloud-Native Video Engine** for programmatic animation. It uses **Docker-in-Docker** isolation and **AI** to allow developers to generate complex mathematical animations (using Manim) directly from the browser.
